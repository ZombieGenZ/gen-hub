# Demo Materials

Thư mục `demo-materials` chứa các tài liệu chuẩn bị cho buổi demo bảo vệ dự án GEN-HUB.

Các file trong thư mục:

- `DEMO-SCRIPT.md`: Kịch bản demo chi tiết theo 5 phần chính.
- `CODE-OWNERSHIP.md`: Phân chia 5 phần code trong source cho 5 người.
- `WORKFLOW.md`: Sơ đồ nghiệp vụ full flow cho 5 anh em và cách các phần liên kết với nhau.

Sử dụng thư mục này làm tài liệu tham khảo khi luyện demo, phân công test và chạy lại kịch bản.
